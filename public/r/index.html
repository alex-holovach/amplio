amplio registry items

/r/registry.json is the machine-readable index.

  • event-http-request — Root HTTP request Event for framework boundary Plugins.
  • plugin-hono — Hono boundary Plugin that closes one HTTP Event per request.
  • plugin-express — Express boundary Plugin spanning callbacks through the final response.
  • plugin-fastify — Fastify boundary Plugin spanning request hooks through final onResponse status.
  • plugin-next — Next.js route-handler boundary Plugin preserving Response identity.
  • plugin-trpc — tRPC contributor Plugin recording nested query and mutation duration Events while leaving subscriptions unchanged.
  • plugin-better-auth — Better Auth contributor Plugin using native after hooks for privacy-safe sign-in and sign-up semantics.
  • plugin-resend — Resend contributor Plugin with privacy-safe email send observations.
  • runtime — Init-only Amplio runtime configuration.
  • sink-console — Console sink that prints Event records as JSON.
  • sink-json — JSONL sink for local Event verification.
  • sink-otlp — OTLP sink that exports Event records over OpenTelemetry.
  • enricher-service-metadata — Resource enricher for bounded deployment name, version, and region attributes.

Install and compose a Plugin with npx @useamplio/cli@alpha add plugin <name> --event <event-id>. Create a project Event with npx @useamplio/cli@alpha add event <event-id>.

npx shadcn@latest add @useamplio/<item> copies open-code source only; use the Amplio CLI for a complete, tracked installation.

Not listed? Project Events live in your repository and do not need a hosted registry item.
