amplio registry items

/r/registry.json is the machine-readable index.

  • event-auth-user-signed-up — Wide event when a user completes sign-up.
  • event-auth-user-signed-in — Wide event when a user signs in.
  • event-email-sent — Wide event when an email is sent.
  • event-payment-order-paid — Wide event when a payment order is paid.
  • middleware-hono — Hono middleware that attaches request-scoped amplio context.
  • middleware-express — Express middleware that attaches request-scoped amplio context.
  • middleware-next — Route-handler wrapper (withAmplio) that owns the request wide event - this is not Next.js middleware.ts.
  • middleware-fastify — Fastify plugin that attaches request-scoped amplio context.
  • middleware-trpc — tRPC middleware that annotates the ambient request wide event with trpc fields (pair with the Next.js route-handler wrapper).
  • sink-console — Console sink that prints wide events as JSON.
  • sink-json — JSON sink that serializes wide events for streaming or files.
  • sink-otlp — OTLP sink that exports wide events over OpenTelemetry.
  • enricher-service-metadata — Enricher that adds service name / environment metadata.
  • enricher-query-allowlist — Enricher that drops http.search by default (or keeps only allowlisted query params) so query-string PII never reaches sinks.
  • enricher-request-metadata — Enricher that adds request id / HTTP metadata.
  • integration-next-auth — NextAuth v5 events hook that emits amplio auth events (uses local message types — no next-auth type imports needed).
  • integration-better-auth — Better Auth helpers that emit amplio auth events.
  • integration-clerk — Clerk helpers that emit amplio auth events.
  • integration-resend — Resend email helpers that emit amplio events (uses local webhook types — no resend package needed).
  • integration-polar — Polar payment helpers that emit amplio order-paid events (uses local webhook types — no @polar-sh/sdk needed).

Install: npx @useamplio/cli@alpha add <kind> <name> (wires everything) or npx shadcn@latest add @useamplio/<item> (drops files; run doctor --fix after).

Not listed? Events generated by amplio add event your.name are starter schemas that exist only in your repo — they are not hosted here.
