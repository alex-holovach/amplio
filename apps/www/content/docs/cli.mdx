```bash
npx @useamplio/cli@alpha <command>
```

The CLI writes ordinary TypeScript into your repository. Generated Event definitions, Plugins,
sinks, and runtime configuration remain yours to review and edit.

## init

```bash
npx @useamplio/cli@alpha init --service my-api
npx @useamplio/cli@alpha add plugin hono
```

Given one installed Hono dependency and one unambiguous `new Hono()` composition root, those two
commands produce and activate:

```text
telemetry/
  events/
    http-request.ts
  plugins/
    hono.ts
  sinks/
    console.ts
  runtime.ts
amplio.json
```

`runtime.ts` calls `init(...)` and exports no logger. `events/http-request.ts` declares the root
Event. `add plugin hono` copies `plugins/hono.ts`, inserts `app.use("*", HonoPlugin())` before the
routes, and records that composition root in `amplio.json`. Runtime code never reads the manifest.

Supported options:

- `--service <name>` sets the generated service name.
- `--package-manager <pnpm|npm|yarn|bun>` overrides detection.
- `--yes` activates and tracks a detected Hono boundary when exactly one supported `new Hono()`
  composition root exists. Ambiguous or unsupported roots abort before generated source writes.
- `--skip-install` writes source without installing dependencies.
- `--paths` or `--no-paths` controls the `~telemetry/*` TypeScript alias.
- `--verbose` streams package-manager output.

Generated source is TypeScript-only.

## Add an Event

```bash
npx @useamplio/cli@alpha add event billing.reconciliation
```

Event IDs are lowercase dot-separated semantics. The command creates
`telemetry/events/billing-reconciliation.ts` with `event({ id, version, schema })`.

Use `--dry-run` to preview and `--force` only when an existing generated file should be replaced.

## Add a Plugin

Install a boundary Plugin without a root selection:

```bash
npx @useamplio/cli@alpha add plugin hono
```

Install a contributor Plugin into a declared root Event:

```bash
npx @useamplio/cli@alpha add plugin resend --event http.request
```

The host must contain one unambiguous `new Resend(...)` construction. If Resend or another Plugin
recipe dependency is missing, the CLI shows the complete runtime/development dependency plan and
package-manager command, then requires interactive approval or `--yes`. A compatible existing
provider version is left untouched; an incompatible version fails closed. Before approval it also
states that Amplio can restore package manifests, lockfiles, source, and lifecycle state, but cannot
undo package-manager caches, `node_modules`, or dependency lifecycle-script side effects. The active
install then:

1. preflight the host's Resend version and one unambiguous client construction seam;
2. copy `telemetry/plugins/resend.ts`;
3. mount `ResendPlugin.events` beneath the selected root tree;
4. wrap the existing `new Resend(...)` expression once;
5. record the source, root Event, branch, and seam in `amplio.json`.

If the client seam is absent or ambiguous, preflight refuses before copying or composing the
Plugin. The installed Plugin is normal application source and can be forked. This alpha does not
run a host formatter over managed Plugin or wiring bytes, so a fresh install remains an exact,
removable recipe base. Use `--dry-run` to perform compatibility, Event-tree, and native-seam
preflight without writing or installing anything.

Use `--target <relative-source-file>` to narrow discovery when a project has multiple candidate
files:

```bash
npx @useamplio/cli@alpha add plugin resend --event http.request --target src/email.ts
```

The target must be an existing, contained source file. Absolute paths, `..`, missing or non-source
files, and symlinks escaping the project fail before writes. Selection does not weaken provider
binding checks or choose between multiple supported seams inside the same file. Once active, a
Plugin cannot be retargeted implicitly; remove and reinstall it explicitly.

Hono, Fastify, constructor, Better Auth, tRPC, and AI SDK telemetry recipes use authenticated native
seams. The AI SDK seam is the generated runtime and does not require `--target`. Next.js and Express
use verified manual adoption: copy the recipe with `--source-only`, attach its documented route
wrapper, then rerun `add plugin` with `--target`. The CLI verifies the exact native route and records
the customer-owned seam without rewriting it. `doctor --strict` re-verifies adopted wiring. Removal
never rewrites it and refuses to delete Plugin source until its live import or reference is detached.

```bash
npx @useamplio/cli@alpha add plugin next --source-only
# attach withAmplio("/stable/route", handler)
npx @useamplio/cli@alpha add plugin next --target app/api/health/route.ts

npx @useamplio/cli@alpha add plugin express --source-only
# spread ...withAmplioRoute("/stable/route", ...handlers) into that same Express route
npx @useamplio/cli@alpha add plugin express --target src/app.ts
```

### AI SDK

AI SDK 7 exposes one native telemetry integration seam for promise-based generation, embeddings, and
reranking. Install and mount the Plugin under an existing root Event:

```bash
npx @useamplio/cli@alpha add plugin ai-sdk --event http.request
```

The command installs the editable recipe and writes an explicit startup registration:

```ts
// telemetry/runtime.ts
import { registerTelemetry } from "ai";
import { AiSdkPlugin } from "./plugins/ai-sdk.js";

registerTelemetry(AiSdkPlugin());
```

Application code continues calling `generateText`, `embed`, `embedMany`, and `rerank` from `ai`.
`streamText` needs the Plugin's explicit wrapper because AI SDK starts global stream telemetry after
the function has already returned. The wrapper composes the native completion, abort, and error
callbacks without consuming the stream or replacing the returned result:

```ts
import { streamText } from "ai";
import { AiSdkPlugin } from "./telemetry/plugins/ai-sdk.js";

const observedStreamText = AiSdkPlugin.streamText(streamText);
const result = observedStreamText({ model, prompt });
```

An unwrapped `streamText` call remains completely untouched and does not claim an incomplete AI
Event. The Plugin records the operation, a fixed provider category and model family, bounded
generation settings, output kind, finish reason, token usage, aggregate item/step/tool/result
counts, bounded performance timings, duration, and outcome. Numeric settings are range-checked,
rounded, or bucketed before they enter the Event.

```json
{
  "@event": "ai.operation",
  "@event_version": 2,
  "operation": "generate_text",
  "provider": "openai",
  "model_family": "gpt-5",
  "max_retries": 2,
  "max_output_tokens": 1024,
  "reasoning_effort": "low",
  "output_kind": "text",
  "tool_count": 3,
  "finish_reason": "stop",
  "input_tokens": 418,
  "output_tokens": 96,
  "step_count": 2,
  "tool_call_count": 1,
  "duration_ms": 842,
  "success": true
}
```

Provider and model values are normalized to fixed low-cardinality enums; raw provider/model IDs are
never copied. The Plugin also excludes call/function IDs, raw seeds, system prompts, prompts,
messages, generated content, reasoning text, tool names/definitions/arguments/results, embeddings,
documents, queries, URLs, headers, provider options/metadata, request/response bodies, and raw
errors.

This recipe supports `ai >=7 <8`. AI SDK 7 is ESM-only and requires Node.js 22 or newer, which is a
stronger requirement than Amplio core. Per-call `telemetry: { isEnabled: false }` disables the
integration, and a per-call `telemetry.integrations` list replaces global integrations for that
call.

## Diff, update, or remove a Plugin

```bash
npx @useamplio/cli@alpha diff plugin resend
npx @useamplio/cli@alpha update plugin resend
npx @useamplio/cli@alpha remove plugin resend
```

An install records the recipe SemVer, SHA-256 digest, nested Event versions, privacy and native
wiring contracts, copied file hashes, and wiring anchors in `amplio.json`. The exact recipe base is
cached at `.amplio/bases/sha256-….json`; reversible pre-install wiring bytes are kept at
`.amplio/installs/resend.json`.

Commit `telemetry/`, `amplio.json`, and `.amplio/` together. The cache contains source snapshots,
not runtime Event data, and is required for reproducible update and removal on another machine.

`diff` reports whether local source or the registry changed. `update` performs a three-way merge
from the cached base, preserving non-overlapping customer edits. It fails without writes for merge
conflicts or changes to Event identity/version, privacy, tree placement, provider instrumenter, or
native wiring. `remove` reverses managed wiring and deletes only unmodified Plugin source. It
always retains provider dependencies because the host application owns them.

## Add delivery configuration

```bash
npx @useamplio/cli@alpha add sink console
npx @useamplio/cli@alpha add sink json
npx @useamplio/cli@alpha add sink otlp
npx @useamplio/cli@alpha add enricher service-metadata
```

Sink and enricher commands preflight `telemetry/runtime.ts` before copying source. If the runtime is
missing or its expected `init(...)` array cannot be recognized, the command aborts without an inert
recipe. A successful command means the operational recipe is already present or was wired into the
runtime configuration.

## list

```bash
npx @useamplio/cli@alpha list
npx @useamplio/cli@alpha list plugin
npx @useamplio/cli@alpha list event --json
```

Kinds are `event`, `plugin`, `sink`, and `enricher`. `--json` produces stable machine-readable
output.

## doctor

```bash
npx @useamplio/cli@alpha doctor --strict
```

Doctor checks `amplio.json`, runtime initialization, Event files and literal IDs, retired alpha
source, tracked Plugin files, composition-root file existence, boundary registration, contributor
Event-tree placement, and the contributor's selected native seam. It does not replace a real
framework request or provider lifecycle test. `--strict` turns warnings such as `--source-only`
Plugins or a missing active boundary into a non-zero exit.

## paths

```bash
npx @useamplio/cli@alpha paths
```

Writes the `~telemetry/*` TypeScript path alias and changes nothing else. Relative imports generated
for generic NodeNext projects use `.js`; Next bundler projects use extensionless specifiers.

## smoke

```bash
npx @useamplio/cli@alpha add sink json
npx @useamplio/cli@alpha smoke http://localhost:3000/health
```

`smoke` sends a request and watches the JSON file sink for a new Event. It reports failure when the
HTTP response arrives but no Event does, turning a missing boundary or wrong port into a visible
diagnostic.

## Safety

- Existing open-code files are preserved unless `--force` is explicit.
- Active Plugin installs preflight before tracked writes.
- Ambiguous native seams abort rather than guessing.
- Contributor construction seams must already exist in the host application. Missing Plugin recipe
  dependencies are installed only after the complete plan and rollback boundary are shown and the
  user approves or passes `--yes`.
- Typecheck the generated graph and exercise a real request; `doctor` is not an end-to-end proof.
