## Add a sink

```bash
npx @useamplio/cli@alpha add sink console
npx @useamplio/cli@alpha add sink json
npx @useamplio/cli@alpha add sink otlp
```

Each command edits `telemetry/logger.ts` — import + append to `init({ sinks: [...] })`.

## Console

```typescript
import { consoleSink } from "./sinks/console";

init({ sinks: [consoleSink] });
```

Emits one JSON line per record to stdout.

## JSON file

Default path includes env: `amplio.development.jsonl` / `amplio.production.jsonl`. Override with `AMPLIO_JSON_SINK_PATH`.

```bash
# .gitignore
amplio*.jsonl
```

## OTLP

Endpoint resolution (OTel spec order):

1. `otlpSink({ endpoint })`
2. `OTEL_EXPORTER_OTLP_LOGS_ENDPOINT` (full URL, used verbatim)
3. `OTEL_EXPORTER_OTLP_ENDPOINT` (base URL, `/v1/logs` appended)

```typescript
otlpSink({ batch: true }) // 100 records / 1s for production
await flush();            // don't lose the last batch on serverless
```

## Enrichers

Run in order before validation. Return value **replaces** the payload (not deep-merge):

```typescript
init({
  enrichers: [
    (record) => ({ ...record, region: process.env.AMPLIO_REGION }),
  ],
});
```

```bash
npx @useamplio/cli@alpha add enricher query-allowlist
```

Drops `http.search` by default to avoid query-string PII.

## Sampling

```typescript
init({
  sampling: {
    rate: 0.1,
    keep: [
      { field: "trpc.type", equals: "mutation" },
      { field: "status", gte: 400 },
    ],
  },
});
```

`keep` rules are OR'd. On rate drop, `.emit()` still returns the record — only sink delivery is skipped.
