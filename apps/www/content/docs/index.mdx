title: Introduction
description: Open-code semantic Events assembled by native Plugins.
---

**Amplio** turns a request, job, message, command, or other meaningful unit of work into one typed
semantic Event. Application code calls ordinary functions; open-code Plugins contribute meaning at
the framework, provider, and local seams where that meaning is already known.

There is no logger to retrieve, mutable context to update, or emit call to remember.

## Quick start

This active walkthrough assumes an existing Hono application with one `new Hono()` composition
root and one `new Resend(...)` client construction.

```bash
pnpm add @useamplio/amplio zod resend
pnpm add --save-dev @useamplio/cli
pnpm exec amplio init --service orders-api
pnpm exec amplio add plugin hono
pnpm exec amplio add plugin resend --event http.request
```

The generated source stays in your repository:

```text
telemetry/
├── events/
│   └── http-request.ts
├── plugins/
│   ├── hono.ts
│   └── resend.ts
├── sinks/
│   └── console.ts
└── runtime.ts
```

## One declared Event tree

```ts
// telemetry/events/http-request.ts
import { event } from "@useamplio/amplio";
import { z } from "zod";
import { ResendPlugin } from "../plugins/resend.js";

export const HttpRequest = event({
  id: "http.request",
  version: 1,
  schema: z.object({
    request_id: z.string(),
    http: z.object({
      method: z.string(),
      route: z.string(),
      status: z.number().int().optional(),
    }),
  }),
  tree: {
    email: ResendPlugin.events,
  },
});
```

The `email` property chooses record placement. `ResendPlugin.events` supplies the exact nested Event
definitions, including their schemas, timing, and bounded cardinality.

## One native seam

The Plugin wraps provider construction once:

```ts
import { Resend } from "resend";
import { ResendPlugin } from "../telemetry/plugins/resend.js";

export const resend = ResendPlugin(new Resend(process.env.RESEND_API_KEY));
```

Every caller keeps the provider's ordinary interface:

```ts
await resend.emails.send(message);
```

Only fields explicitly selected by the Plugin enter telemetry. The generated Resend Plugin records
a stable provider name and optional template tag; it excludes recipients, subject, body, headers,
and credentials.

## One lifecycle owner

The framework Plugin keeps the root Event open for the complete framework lifecycle. In Hono, it
wraps `await next()`. In Express, it begins before the first route handler and settles when the
response finishes. In Fastify, it spans `onRequest` through `onResponse`. In Next, it wraps a route
handler with an explicit stable route template.

```ts
const app = new Hono();
app.use("*", HonoPlugin());

app.post("/orders", async (context) => {
  const order = await placeOrder(await context.req.json());
  return context.json(order, 201);
});
```

The handler knows nothing about Amplio.

## One immutable record

```json
{
  "@event": "http.request",
  "@event_version": 1,
  "service": "orders-api",
  "env": "production",
  "timestamp": "2026-08-14T07:00:00.000Z",
  "request_id": "req_01K2...",
  "duration_ms": 84,
  "success": true,
  "http": {
    "method": "POST",
    "route": "/orders",
    "status": 201
  },
  "email": {
    "sends": [
      {
        "provider": "resend",
        "template": "order_confirmation",
        "duration_ms": 42,
        "success": true
      }
    ]
  }
}
```

The record is validated, sanitized, redacted, sampled, detached from application state, and then
sent to configured sinks.
