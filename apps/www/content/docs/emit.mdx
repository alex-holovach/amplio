## Define a root Event

```ts
import { event } from "@useamplio/amplio";
import { z } from "zod";

export const BillingReconciliation = event({
  id: "billing.reconciliation",
  version: 1,
  schema: z.object({
    date: z.string(),
    accounts_checked: z.number().int().nonnegative().optional(),
  }),
});
```

Wrap the boundary function once:

```ts
export const reconcileBilling = BillingReconciliation.handle(
  reconcileBillingNative,
  {
    input: ({ args: [date] }) => ({ date: date.toISOString() }),
    result: ({ result }) => ({
      accounts_checked: result.accountsChecked,
    }),
  },
);
```

The wrapper preserves arguments, return values, thrown values, `this`, sync behavior, and native
Promise identity. It finalizes automatically.

## Observe a duration Event

Duration Events describe calls that already exist:

```ts
const Charge = event({
  id: "stripe.charge",
  version: 1,
  schema: z.object({
    amount_cents: z.number().int(),
    payment_id: z.string().optional(),
  }),
  timing: "duration",
  cardinality: { many: { max: 4 } },
});

export const StripePlugin = plugin({
  id: "stripe",
  events: { charges: Charge },
  instrument({ events, observe }) {
    return function instrumentCharge(charge) {
      return observe(events.charges, charge, {
        input: ({ args: [input] }) => ({
          amount_cents: input.amountCents,
        }),
        result: ({ result }) => ({ payment_id: result.id }),
      });
    };
  },
});
```

Mount the exact definitions in a root Event:

```ts
export const Checkout = event({
  id: "checkout",
  version: 1,
  schema: CheckoutFields,
  tree: {
    payments: StripePlugin.events,
  },
});
```

Calls outside an active root still run normally and contribute nothing.

## Record an instant Event

```ts
const SignedIn = event({
  id: "auth.signed_in",
  version: 1,
  schema: z.object({ method: z.string(), user_id: z.string() }),
  timing: "instant",
  cardinality: { many: { max: 4 } },
});

export const AuthPlugin = plugin({
  id: "auth",
  events: { signed_in: SignedIn },
  instrument({ events, record }) {
    return (value) => record(events.signed_in, value);
  },
});
```

`record()` adds no timing fields. It accepts only an instant Event owned by that Plugin.

## Span native hooks

When no single function represents the full duration, `begin()` returns a handle:

```ts
export const PaymentPlugin = plugin({
  id: "payment",
  events: { attempts: PaymentAttempt },
  instrument({ events, begin }) {
    return (input) => begin(events.attempts, input);
  },
});

const attempt = PaymentPlugin({ attempt: 1 });
attempt.run(startNativeWork);
attempt.update({ state: { phase: "confirmed" } });
attempt.end({ provider_id: "pay_1" });
```

Use `fail(error, fields)` for failure and `cancel(reasonCode)` when native lifecycle ends without a
semantic result. `run()` and `bind()` preserve Event context across callbacks.

Boundary Plugin authors use `openEvent()` for the same reason when a framework exposes completion
through response hooks rather than a returned Promise.

## Failure and pending work

- A thrown value or rejected native Promise keeps exact application behavior.
- A duration Event receives `success: false` and bounded structured error metadata.
- A returned HTTP status can use a `success` projector, such as `status < 400`.
- A nested observation still pending when the root closes is omitted and diagnosed.
- Duplicate single occurrences reserve first and drop later writes.
- Bounded arrays drop newest overflow and report truncation metadata.

Telemetry projection, schema, redaction, sampling, and sink failures never replace application
results or errors.

## Schema contract

Schemas validate synchronously so wrappers do not change application timing. Zod and synchronous
Standard Schema v1 validators are supported. Asynchronous validation is consumed safely and treated
as unsupported rather than awaited.

## Test by exact Event identity

```ts
import { init } from "@useamplio/amplio";
import { createTestSink } from "@useamplio/amplio/testing";

const events = createTestSink();
init({ service: "orders-test", env: "test", sinks: [events] });

await reconcileBilling(new Date("2026-08-14"));

expect(events.single(BillingReconciliation)).toMatchObject({
  "@event": "billing.reconciliation",
  accounts_checked: 12,
});
events.assertNoDiagnostics();
```

Selection uses the exact definition value, not only its string ID.
