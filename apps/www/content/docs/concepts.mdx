## Wide events

One record per unit of work. Accumulate context with `.set()`, finalize with `.emit()`. After emit, the instance is **sealed** — further `.set()` / `.error()` are no-ops (with a dev warning) and repeat `.emit()` returns `null`.

## Schema-first

Every important event is declared with `defineEvent` before use:

```typescript
import { defineEvent } from "@useamplio/amplio";
import { z } from "zod";

export const PostCreated = defineEvent(
  "post.created",
  z.object({
    post: z.object({ id: z.string(), title: z.string() }),
  }),
);
```

Validation runs at emit time. Outside `NODE_ENV=test`, failures soft-tag the record with `validation.issues` and set `success: false` unless `init({ strict: true })`.

## Open code in telemetry/

Events, middleware, sinks, enrichers, and integrations live in `telemetry/` — owned by your app, not hidden in `node_modules`. The CLI scaffolds; you edit.

```
telemetry/
├── events/       # one file per schema
├── middleware/   # hono, next, trpc, …
├── sinks/        # console, json, otlp, …
├── enrichers/
├── integrations/
└── logger.ts     # init() + exported logger
```

## Request spine + domain events

HTTP middleware emits one **spine** row (`http.request` or `trpc.request`). Domain events are separate rows correlated by `request_id`:

```typescript
import { getLogger } from "@useamplio/amplio";

// inside request scope:
getLogger()
  .child(AuthUserSignedUp)
  .set({ user: { id: "u_123" }, signup: { method: "email" } })
  .emit();
// → spine row + domain row, same request_id
```

| API | Use when |
|---|---|
| `.child(EventDef)` | **Canonical.** Fresh seal and start time; copies `request_id` only (no `http.*` duplication). Emitting the child does not seal the spine |
| `getLogger().set({ … })` | Annotate the spine row (middleware emits it) |
| `logger.event(Def).emit()` | Standalone row outside a request; inside request scope it also copies `request_id` (since alpha.8) |

Since alpha.13, `getLogger().event(Def)` on an already-named spine behaves as `.child(Def)` — a separate correlated row, spine preserved — with a dev notice suggesting the explicit spelling. `.child()` remains the canonical API.

## Public runtime surface

The frozen public surface from `@useamplio/amplio`:

- `defineEvent`, `init`, `logger.event`, `logger.create`, `getLogger`
- `.set()`, `.child()`, `.time()`, `.error()`, `.emit()`, `flush()`

`getLogger()` returns the request-scoped logger from middleware context; outside request scope it returns a **no-op logger** (it does not throw). `useLogger` is a deprecated alias — renamed to `getLogger` in alpha.10 because it is not a React hook and `use*` naming trips React lint rules.

No `log.info` / `log.warn` — use schema fields and `.error()` for structured failures.

## Library-first silence

Call `.set()` / `.emit()` before `init()` ran and `.emit()` returns `null` — no sinks run, nothing throws, and dev builds warn on every dropped emit. Call `init()` with at least one sink (from `telemetry/logger.ts`) when you want output.
